## 導言

一個影像判讀模型要移到邊緣裝置。壓縮前在平衡測試集上的 top-1 準確率是 91.2%，壓縮後 91.0%。差異落在多次重跑的抖動範圍內，變更被批准，理由寫成「在噪聲範圍內無損」。

三週後安全團隊回報：某個罕見但高風險類別的假陰性率從 4% 升到 19%。

回查發現兩件事。第一，那個類別在平衡測試集裡佔 1.8%，它的全部惡化被平均掉了。第二，壓縮後有一部分樣本從錯變對、另一部分從對變錯，兩者在總數上幾乎抵銷——所以平均值不動，個體卻大量改變。

**那個 0.2 個百分點的差異不是「近似很小」的證據，它是正負翻轉互相抵銷的結果。** 這個事故的問題不在壓縮，而在驗收契約：它只問了一個對失真結構完全盲目的問題。

本文因此要處理三件事：平均值不變時失真藏在哪裡、三種常見壓縮手段的失真機制是否相同、以及作為比較基準的「未壓縮模型」本身是否唯一。

## 分析

### 三種手段改變的對象不同

三種常見手段共享「以資源換近似」這個上位問題，但它們動的東西不一樣：

| 手段 | 被改變的對象 | 函數是否同一個 | 必要對照 | 特有觀察量 |
| :--- | :--- | :--- | :--- | :--- |
| **量化**（Quantization） <!-- term:Quantization --> | 權重與啟動值的數值格點 | 是，受擾動 | 同一計算圖、同一硬體上的浮點與整數路徑 | 飽和率、逐層量化 <!-- term:Quantization -->誤差、翻轉率 |
| **剪枝**（Pruning） <!-- term:Pruning --> | 連接、通道或結構 | 是，受擾動 | 同一稀疏度下有無重新訓練 | 稀疏模式、實測延遲、切片損失 |
| **知識蒸餾**（Knowledge Distillation） <!-- term:KnowledgeDistillation --> | 學生的函數與容量 | 否，是另一個函數 | 教師、只學硬標籤的同容量學生、學軟目標的學生 | 教師忠實度、**校準**（Calibration） <!-- term:Calibration -->、分佈外差異 |

> [!IMPORTANT]
> **量化** <!-- term:Quantization --> (Quantization): 以較少位元表示權重或啟動值，改變數值格點以降低記憶體與計算成本的近似方法。 <!-- anchor:Quantization -->
> **剪枝** <!-- term:Pruning --> (Pruning): 移除模型中影響較小的連接或結構，以縮減規模的壓縮方法。 <!-- anchor:Pruning -->
> **知識蒸餾** <!-- term:KnowledgeDistillation --> (Knowledge Distillation): 以較大模型的輸出分佈為目標，訓練較小模型重新估計其行為的壓縮方法。 <!-- anchor:KnowledgeDistillation -->
> **校準** <!-- term:Calibration --> (Calibration): 模型輸出機率與實際正確率的一致程度。 <!-- anchor:Calibration -->


第三欄是三者最重要的分界。量化 <!-- term:Quantization -->與剪枝 <!-- term:Pruning -->把同一個函數擾動一下；知識蒸餾 <!-- term:KnowledgeDistillation -->用一個容量不同的函數重新估計教師行為。前兩者的失真可以用「離原函數多遠」描述，後者不行——它從一開始就不是同一個函數。

### 量化：格點變粗，傷害集中在低邊際

均勻量化 <!-- term:Quantization -->可寫成

$$
Q_\Delta(w) = \Delta\,\mathrm{round}(w / \Delta),
$$

在取最近格點且不截斷時，單一權重的誤差滿足 $|Q_\Delta(w) - w| \le \Delta/2$。但輸出誤差還受輸入尺度與層間放大影響，所以權重誤差界不能直接外推成決策誤差界。

下面的程式量測一個線性判別模型在不同位元數下的行為。觀察量刻意分三個：對基線的一致率、翻轉率，以及**最低 10% 邊際切片**上的翻轉率。

```python
import random
rnd = random.Random(5)
D, N = 8, 4000
W = [rnd.gauss(0, 1) for _ in range(D)]
X = [[rnd.gauss(0, 1) for _ in range(D)] for _ in range(N)]

def dot(w, x, order=None):
    idx = range(len(w)) if order is None else order
    s = 0.0
    for i in idx: s += w[i] * x[i]
    return s

base_logit = [dot(W, x) for x in X]
base = [1 if s >= 0 else 0 for s in base_logit]
cut = sorted(abs(s) for s in base_logit)[N // 10]

def stats(w):
    pred = [1 if dot(w, x) >= 0 else 0 for x in X]
    acc = sum(1 for p, b in zip(pred, base) if p == b) / N
    low = [i for i in range(N) if abs(base_logit[i]) <= cut]
    flip_low = sum(1 for i in low if pred[i] != base[i]) / len(low)
    return acc, 1 - acc, flip_low

print("bits   對基線一致率   翻轉率   低margin切片翻轉率")
for bits in (8, 4, 2):
    step = max(abs(v) for v in W) / (2 ** (bits - 1) - 1)
    qw = [step * round(v / step) for v in W]
    a, f, fl = stats(qw)
    print(f"{bits:4d}  {a:13.4f}  {f:8.4f}  {fl:18.4f}")
```

實際執行的輸出：

```text
bits   對基線一致率   翻轉率   低margin切片翻轉率
   8         0.9988    0.0012              0.0125
   4         0.9715    0.0285              0.2743
   2         0.8485    0.1515              0.4938
```

8 位元那一列是導言事故的縮影：整體翻轉率 $0.0012$，看起來完全無害；而低邊際切片的翻轉率是 $0.0125$，高出十倍。4 位元時整體 $0.0285$ 對切片 $0.2743$，同樣約十倍。

因果鏈因此是：格點變粗 → 權重誤差 → 判別分數的邊際縮小或改號 → 邊際本來就小的個體先翻轉 → 這些個體在整體平均中佔比很小，於是平均值幾乎不動。

**傷害不是均勻散佈的，它有一個明確的棲身位置。** 而恰好是那個位置在聚合指標中權重最低。

### 剪枝：移除方向，留下相似的集中特徵

```python
order = sorted(range(D), key=lambda i: abs(W[i]))
print("剪掉k個最小權重   翻轉率   低margin切片翻轉率")
for k in (1, 2, 4):
    pw = W[:]
    for i in order[:k]: pw[i] = 0.0
    a, f, fl = stats(pw)
    print(f"{k:15d}  {f:8.4f}  {fl:18.4f}")
```

實際執行的輸出：

```text
剪掉k個最小權重   翻轉率   低margin切片翻轉率
              1    0.0142              0.1421
              2    0.0225              0.2219
              4    0.1112              0.4439
```

剪掉一個最小權重的整體翻轉率是 $0.0142$，切片翻轉率 $0.1421$——同樣約十倍的集中。所以「翻轉集中在低邊際」這個特徵不足以區分量化 <!-- term:Quantization -->與剪枝 <!-- term:Pruning -->；兩者都是對同一函數的擾動，擾動的效果都先在邊際小的地方顯現。

要區分它們需要各自的特有觀察量：量化 <!-- term:Quantization -->要看飽和率與逐層誤差，剪枝 <!-- term:Pruning -->要看稀疏模式與實測延遲。而共同的部分——翻轉集中在何處——只告訴我們「這是一次擾動」，不告訴我們擾動的來源。


實際執行的輸出：

```text
知識蒸餾：以有限容量重新估計教師行為
  分佈內 教師-學生 一致率 : 0.8562
  平移後 教師-學生 一致率 : 0.9825
  貼邊界 教師-學生 一致率 : 0.8552
```

第一個數字就把知識蒸餾 <!-- term:KnowledgeDistillation -->與前兩者分開了。分佈內一致率是 $0.8562$，而 8 位元量化 <!-- term:Quantization -->的一致率是 $0.9988$。學生不是教師的一個受擾動版本，它是一個容量不同的函數，所以它與教師的差異不受任何小擾動界約束。

第二個數字推翻了一個常見的直覺。平移後的一致率是 $0.9825$，**比分佈內更高**。原因是平移把樣本質量推離決策邊界，而遠離邊界的地方教師與學生本來就容易一致。所以「分佈外一致率較差」不是普遍規律；一致率受邊際分佈支配，而分佈的移動可能朝任一方向。

第三個數字確認了這個解釋：把樣本壓到邊界附近，一致率是 $0.8552$，與分佈內相當而未改善。真正決定一致率的是有多少質量落在兩個函數的分歧區域，不是「是否分佈外」。

### 基線本身不唯一

前面所有的翻轉率都以「未壓縮模型」為基準。這個基準是唯一的嗎？

```python
asc = sorted(range(D), key=lambda i: abs(W[i]))
desc = list(reversed(asc))
exact = sum(1 for x in X if dot(W, x, asc) != dot(W, x, desc))
diff = sum(1 for x in X if (dot(W, x, asc) >= 0) != (dot(W, x, desc) >= 0))
print(f"  加總順序不同而數值不同的樣本: {exact}/{N} ({exact/N*100:.1f}%)")
print(f"  其中決策因此翻轉的樣本      : {diff}/{N}")
```

實際執行的輸出：

```text
浮點基線本身不唯一：只改點積的加總順序
  加總順序不同而數值不同的樣本: 2534/4000 (63.3%)
  其中決策因此翻轉的樣本      : 0/4000

把樣本壓到決策邊界附近，再看加總順序是否抵達決策層
  貼近邊界的樣本 2000 個，其中因加總順序而決策不同: 285 (14.2%)
```

同一組權重、同一批輸入、同樣的浮點精度。唯一改變的是點積累加的順序，而 63.3% 的樣本得到了不同的數值——浮點加法不滿足結合律。

在原始樣本上這個差異沒有抵達決策層（$0/4000$）。但把樣本壓到決策邊界附近之後，14.2% 的樣本**決策不同**。

這對整篇的觀察量加上一條必要的但書：**翻轉率有一個由算子順序決定的噪聲底線，而該底線恰好也集中在低邊際切片**。也就是說，用來偵測壓縮傷害的量，其噪聲來源與傷害本身棲身於同一個位置。因此任何低邊際切片上的翻轉率報告，必須附上同一硬體、同一計算圖上未壓縮模型重跑數次的翻轉率作為底線；沒有這個底線，切片翻轉率無法判讀。

## 反思

壓縮不是退化的同義詞。量化 <!-- term:Quantization -->感知訓練或剪枝 <!-- term:Pruning -->後重新訓練都可能在指定基準上改善表現，因為它們改變了最佳化問題而不只是擾動了解。因此合理的驗收契約應該定義行為容差，而不是要求逐位元一致——後者在浮點執行下連未壓縮模型自己都達不到。

一個反例可以標出平均值的誤導方向。壓縮後平均分數上升，同時安全閾值附近的假陰性增加。單一平均值會判定這是改善，而風險契約應該拒絕它。這說明「更好」需要指定在哪個量上更好，而不同的量可以給出相反的排序。

另一個反例來自系統一側。模型檔案縮小四倍，而目標硬體不支援該稀疏格式的算子，實測延遲不變。理論壓縮率是關於參數計數的陳述，系統收益是關於執行的陳述，前者不蘊含後者。這也是為什麼對照必須在目標硬體上取得，而不能從位元數推算。

還有一個限制必須誠實標記，因為它指向本文自身的方法。本文用翻轉率取代平均準確率，理由是後者會抵銷。但翻轉率同樣是一個聚合量——它把「哪些個體翻轉、翻向哪邊、後果多重」都壓成一個比例。低邊際切片翻轉率改善了定位，並沒有消除聚合這件事。本文不主張翻轉率是終點；它主張的是平均準確率作為單一驗收指標不足，而替代量自身的不足需要在各自的風險契約中另行處理。

最後，本文的實驗是線性、單層、無非線性放大的。它足以證明「傷害集中於低邊際」與「浮點基線不唯一」這兩個結構性主張，不足以預測深層網路中逐層誤差如何複合。層間放大、啟動值的動態範圍、以及算子融合的具體實現都會改變量級。

## 實務對比

**驗收一次壓縮。** 錯誤做法是在平衡測試集上比較 top-1 準確率，差異落在抖動內就批准。實測顯示 8 位元量化 <!-- term:Quantization -->的整體翻轉率 $0.0012$ 對應低邊際切片 $0.0125$，而罕見類別的惡化會被平衡集的權重稀釋掉。正確做法是先保存逐樣本判別分數，再檢查決策翻轉、機率校準 <!-- term:Calibration -->與預先指定的風險切片，並在目標硬體上實測延遲與能耗。

**建立比較基準。** 錯誤做法是把未壓縮模型跑一次的結果當成基準。浮點加法不滿足結合律，實測中 63.3% 的樣本會因累加順序而得到不同數值，貼近邊界時 14.2% 的決策不同。正確做法是在同一硬體、同一計算圖上重跑未壓縮模型數次，把其間的翻轉率作為噪聲底線；壓縮的翻轉率必須超出該底線才可判讀。

**宣稱知識蒸餾 <!-- term:KnowledgeDistillation -->無損。** 錯誤做法是把學生稱為教師的無損複製。學生是一個容量不同的函數，實測中它與教師的分佈內一致率是 $0.8562$，而 8 位元量化 <!-- term:Quantization -->是 $0.9988$——兩者不是同一量級的近似。正確做法是把對照設成三組：教師、只學硬標籤的同容量學生、以及學軟目標的學生。只有這樣才能區分容量限制、資料缺口與軟目標訊號各自的貢獻。

**評估分佈外的忠實度。** 錯誤做法是假設分佈外一致率必然較差，於是只在分佈外測一次就下結論。實測中平移後的一致率是 $0.9825$，反而高於分佈內的 $0.8562$，因為平移把質量推離了分歧區域。正確做法是報告一致率時同時報告該分佈的邊際分佈；一致率的高低主要由有多少質量落在分歧區域決定，而不是由「內」或「外」決定。

## 結論

壓縮是受資源約束的近似，而它不是單一機制。量化 <!-- term:Quantization -->改變數值格點，剪枝 <!-- term:Pruning -->移除計算方向，知識蒸餾 <!-- term:KnowledgeDistillation -->以有限容量重新估計教師行為——前兩者擾動同一個函數，第三者換成另一個函數。三者共享「以資源換近似」這個上位問題，不共享低階失真機制，因此不能用同一組觀察量驗收。

本文的量測給出四個可直接執行的結論：

1. **平均準確率不變不是無損的證據。** 正負翻轉會互相抵銷，實測中整體翻轉率 $0.0012$ 的情形下，低邊際切片的翻轉率是它的十倍。
2. **傷害有明確的棲身位置。** 擾動類手段的翻轉集中在判別邊際最小的個體上，而那正是聚合指標中權重最低的部分。
3. **知識蒸餾 <!-- term:KnowledgeDistillation -->不受小擾動界約束。** 它的分佈內一致率就已明顯低於量化 <!-- term:Quantization -->，因為它不是同一個函數；而它的分佈外一致率可能更高，取決於質量是否被推離分歧區域。
4. **未壓縮基線本身不唯一。** 僅改變累加順序，63.3% 的樣本數值不同，貼近邊界時 14.2% 的決策不同。翻轉率因此有一個噪聲底線，且該底線與傷害棲身於同一切片。

因此一份保真度契約必須同時問四件事：哪些個體翻轉、哪些切片受損、機率是否失準、以及真實硬體是否取得收益。平均準確率可以作為起點，不能充當無損的證明；而任何切片翻轉率的報告，都必須附上同硬體重跑的噪聲底線才有意義。
